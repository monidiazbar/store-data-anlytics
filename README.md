# 📊 Análisis Alura Store - Desempeño de Tiendas

## 📌 Descripción del Proyecto
**Alura Store - Análisis de Ventas y Rendimiento de Tiendas**

Proyecto desarrollado como parte del desafío del programa Oracle ONE a través de Alura Latam. El objetivo es ayudar al señor Juan a determinar qué tienda debe vender para invertir en un nuevo negocio, mediante un análisis completo del desempeño de cuatro tiendas.

## 🎯 Objetivo del Análisis
Evaluar cuál de las cuatro tiendas tiene el desempeño más bajo basándose en cinco métricas clave:
1. **Facturación total** de cada tienda
2. **Categorías más populares** por tienda
3. **Promedio de evaluación** de los clientes
4. **Productos más y menos vendidos**
5. **Costo promedio de envío**

## 🛠️ Tecnologías Utilizadas
- **Python 3.x**
- **Pandas** - Análisis de datos
- **NumPy** - Cálculos numéricos
- **Matplotlib/Seaborn** - Visualización
- **Google Colab** - Entorno de ejecución

## 📊 Secciones del Análisis

### 1. Facturación Total
- Cálculo del total de ventas por tienda
- Comparación del rendimiento financiero

### 2. Ventas por Categoría
- Identificación de categorías más populares
- Análisis de preferencias por tienda

### 3. Evaluación de Clientes
- Cálculo del promedio de calificaciones
- Análisis de satisfacción del cliente

### 4. Productos Más y Menos Vendidos
- Ranking de productos por volumen
- Identificación de oportunidades de mejora

### 5. Costo Promedio de Envío
- Análisis de eficiencia logística
- Impacto en margen de ganancia

## 📈 Resultados y Recomendación
Basado en el análisis integral de las cinco métricas, se identificará:
- **Tienda con menor rendimiento**
- **Razones específicas del bajo desempeño**
- **Recomendación fundamentada** para la venta

## 📋 Informe final
El informe final incluirá:
- Resumen ejecutivo de hallazgos
- Gráficos comparativos
- Recomendación con justificación
- Posibles estrategias de mejora para las tiendas restantes
